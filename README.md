# Hello World 教学项目

欢迎来到 GitHub 零基础实战课堂！这是教师提供的官方教学项目。

## 项目简介

本项目是一个最简单的 Python 入门程序，运行后会输出：

```
Hello World!
```

同学们将围绕这个项目完成 GitHub 核心技能的实战训练：搜索项目 → Star 收藏 → Fork 复刻 → 下载代码 → 本地运行 → 修改代码 → 提交到自己的 GitHub。

## 课前准备

- 一个 [GitHub](https://github.com) 账号
- [Visual Studio Code](https://code.visualstudio.com) 编辑器
- [Python](https://www.python.org) 环境（安装时请勾选 “Add Python to PATH”）
- Git 工具（VSCode 通常自带）

## 运行方法

1. 将代码下载或 Fork 到本地；
2. 用 VSCode 打开本项目文件夹；
3. 在终端中运行：

```bash
python hello.py
```

4. 看到终端输出 `Hello World!` 即表示运行成功。

## 实战任务

| 任务 | 内容 |
| ---- | ---- |
| 任务一 | 搜索教师的教学项目 |
| 任务二 | Star 收藏项目 |
| 任务三 | Fork 复刻项目 |
| 任务四 | Download 下载代码到本地 |
| 任务五 | 用 VSCode 打开并运行代码 |
| 任务六 | 修改代码并提交到个人 GitHub |
| 任务七 | 创建自己的仓库并上传代码 |

## 修改练习

运行成功后，请把 `hello.py` 中的：

```python
print("Hello World!")
```

修改为：

```python
print("你好，我是XXX")
```

（把 `XXX` 替换成你的真实姓名或昵称），然后提交到你的 Fork 仓库，完成属于自己的第一次 GitHub 提交。
